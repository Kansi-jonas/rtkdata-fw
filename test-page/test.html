RTKdata Board Test

Firmware test build for hardware bring-up. Status refreshes every second. connecting...

Board ...

Boot counters survive restarts. "power-on / EN" counts power cycles and EN resets. "software" counts firmware restarts: this page, a factory reset, or the supervisor (for example low memory).

Report ...

The page keeps writing one report across restarts, power cycles and reloads of this page: every boot and every test result it sees, listed above. It is stored in this browser for this board, so keep using the same browser and the same address (hotspot or Ethernet IP) for the whole test. Before the next restart, wait until the new boot and the test results show up here.

Power and revision ...

PoE voltage reads GPIO36 (low = PoE module delivers 5 V). Check it once on PoE only and once on USB only. Revision ID reads the GPIO35 divider once at boot: about 1650 mV on K_EVK_V4.1.

Ethernet ...

Needs a router or switch with DHCP for an IP address. PASS = link at 100 Mbit full duplex and 0 symbol errors. Unplug and replug the cable: "link ups" counts up by one.

Wi-Fi ...

    GNSS (UM980) ...

    "Reset GNSS" pulses the UM980 reset line, then sends the full configuration again (takes several seconds). A real reset stops the PPS: "longest PPS pause" then shows several seconds. PPS needs an antenna with sky view.

    Button SW1 ...

    Short presses only. Holding the button for 6 seconds erases the configuration (factory reset). Every press also resets the UM980 in hardware.

    LEDs

    NTRIP (GPIO12)
    Wi-Fi (GPIO32)

    "Auto" gives the LED back to the firmware. Power, PoE, PPS and the RJ45 LEDs are hardware only.

    Crypto chip ATECC608B ...

    I2C at address 0x60, SDA GPIO15, SCL GPIO4. Only for K_EVK_V4.1: on a reworked V4.0 GPIO15 is still the GNSS reset, so the page asks first, and the firmware also checks the revision ID.

    Memory ...

    PASS = internal RAM never fell below 16 KB since boot (the supervisor restarts the unit at 12 KB).
